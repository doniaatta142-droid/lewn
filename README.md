# LEWN - Women's Accessories Store
Responsive e-commerce MVP for LEWN.

Stack: HTML, CSS, JavaScript + Node.js/Express.
Run backend: `cd backend && npm install && npm start`
Backend: http://localhost:3000
Frontend: open `frontend/index.html`.

This is an MVP/demo: data is in memory. Production needs a database, secure auth, real payments, shipping, and admin authorization.
